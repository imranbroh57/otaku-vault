# ⚡ Otaku Vault

An ultra-lightweight, standalone anime tracking web application built with **HTML5, Vanilla CSS, JavaScript**, and powered by the **AniList GraphQL API** & **Firebase**.

🌐 **Live Demo:** [https://imranbroh57.github.io/otaku-vault/]

---

## ✨ Features

- ⚡ **Ultra-Lightweight Storage:** Uses an optimized string key-value structure in Firestore saving near-zero bandwidth and storage quota.
- 📱 **PWA Ready:** Installable directly to your mobile home screen with native app feel.
- 🔄 **Real-Time Silent Cloud Sync:** Auto-syncs your progress whenever an anime is saved, moved, or episode count is adjusted.
- 🔍 **Live Search & Instant Suggestions:** Real-time autocomplete suggestions powered by AniList.
- 🎯 **Advanced Discovery:** Filter by Genre, **This Season**, and **Top Rated** anime.
- 📊 **Episode Progress Tracker:** Custom tap-to-edit counters and interactive +1/-1 controls.
- 🔐 **Firebase Auth:** One-click Google login support with automatic authorized domain protection.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3 (Custom Dark Theme), Vanilla JavaScript
- **API:** AniList GraphQL API
- **Cloud Backend:** Firebase Auth (Google) & Cloud Firestore
- **Deployment:** GitHub Pages
